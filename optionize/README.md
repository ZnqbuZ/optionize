# optionize

Core crate for the `optionize` framework. This crate provides `PartialOptionized`, `Optionizable`, and `Optionized` for converting, applying, and merging patches, plus `Retain` for removing updates that already match a complete or partial baseline.

It also re-exports the macros from `optionize-macros` for convenience.

For full documentation and examples, please see the [workspace README](../README.md).

## Usage

```toml
[dependencies]
optionize = "0.5"
```
